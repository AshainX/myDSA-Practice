# 00 — START HERE (Rules of the Game)

Welcome. This is your personal DSA training ground. Read this once, then forget it and just code.

## Workflow (every set)

1. Open the current `setN/` folder in VSCode.
2. Read the `README.md` in the module folder (mini lesson + syntax cheatsheet).
3. Solve the problems `q01` → `q10` **in order**. Each has a `main()` with visible tests — run it to self-check.
4. When a problem is done, come back to the chat. I will **compile and run your file myself** with hidden edge tests to verify accuracy (not just your claim).
5. We review together, log the result, and only when the set passes do we unlock the next.

## Grading per question

- ✅ **Clean** — solved with 0 logic hints + passes my hidden edge tests. Full point.
- 🤝 **Assisted** — you used 1 hint. Solved, but must redo one fresh question of the same type to convert it to ✅.
- ❌ **Stuck** — not solved. I give a new question on the same concept to retry.

## Hint policy

- **Syntax help** ("why won't this compile", a typo, a missing `#include`) → **FREE**, never counts as a hint.
- **Logic nudge** (how to approach the problem, what algorithm to use) → counts as 1 hint = Assisted.
- You may ask freely, but every hint is logged. Many hints = weak spot → I add a targeted mini-set.

## Thresholds (to unlock the next set)

- **My threshold:** ≥ 8 ✅ out of 10, with assisted ones converted. Total logic hints across the set ≤ 5.
- **Your threshold:** you must honestly feel confident, not just satisfy me. If you don't, we stay and add volume.
- **Both** must pass to move on. Otherwise: fresh questions, same level.

## Honesty rule

Never use AI to write the logic. If you do, the whole point is lost — you'd only be fooling yourself. Code must be YOUR thinking. I'm here to check it, not to cheat with you.

## Rules while coding

- Write the logic yourself. I only guide, review, and unlock.
- Read the problem statement carefully — half the battle is understanding what's asked.
- Type code yourself (no copy-paste of AI) so your fingers learn too.
